About this document

This is a demonstration of the ComplianceOS EDU binder, built to show what the product hands a monitor. Sample County Schools does not exist. Every figure, name, signature and hash is illustrative.

The indicator structure is real. Section 18 and its five indicators were transcribed from a published Georgia monitoring result — the Cross Functional Monitoring Indicator Report, FY2025, for a real district — because GaDOE's own instrument PDFs are not currently retrievable from gadoe.org. The requirement wording here is paraphrased from that report rather than quoted from GaDOE's issued document, and must be reconciled against the FY2027 CFM Document before it is relied on. The $14,400 parent mentor minimum comes from the same source and carries the same caveat.

Palette, typography and the rule that status is never encoded by colour alone are taken from docs/design/landing-page-direction.md. Indicator numbering is Georgia's and is never renumbered. The model behind it is packages/evidence; the decision behind it is ADR 0006.
